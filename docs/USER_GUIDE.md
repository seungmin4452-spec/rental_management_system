# RentalDesk(렌탈데스크) 사용 설명서

> 대상 버전: **1.0.0** · 지원 환경: **Windows 11 (64비트)**
> 설치와 라이선스 등록은 `설치 안내서`(docs/customer/INSTALL_GUIDE.md)를 먼저 보세요.
> 궁금한 점은 **크몽 주문 메시지**로 문의해 주세요. 문의할 때 [도움말 > 프로그램 정보·문의]의 버전과 운영체제를 함께 알려 주시면 빠르게 확인할 수 있습니다.

## 1. 빠른 시작 (10분)

1. **처음 실행** — 라이선스 창이 열립니다. 라이선스 파일을 받기 전이면 **[예제 데이터로 체험]**을 눌러 미리 써 볼 수 있습니다. 예제 데이터는 실제 데이터와 따로 저장됩니다.
2. **라이선스 등록** — 판매자에게 받은 파일을 **[라이선스 파일 불러오기…]**로 고르면 실제 데이터 화면이 열립니다.
3. **시작 도우미** — 실제 데이터가 비어 있으면 "취급하는 장비를 모두 고르세요" 창이 나옵니다. 카메라·공구·캠핑·행사·유아용품 중 고르면 카테고리와 추천 설정(반납 후 준비 시간, 연체 설정 등)이 준비됩니다. 건너뛰어도 되고, 나중에 [도움말 > 시작 도우미]로 다시 열 수 있습니다.
4. **설정** — [설정]에서 사업자 정보, 출력물 문구(대여 약관), 요금 계산 방식, 데이터 백업·복원을 확인합니다.
5. **장비 등록** — [장비 관리 > 장비 등록]. 장비 한 대마다 고유 장비 번호를 붙입니다(같은 모델 3대 = 장비 3개). 기존 엑셀 목록이 있으면 **[엑셀로 가져오기]**로 한 번에 등록합니다.
6. **고객 등록** — [고객 관리 > 고객 등록]. 예약하면서 바로 등록해도 됩니다.
7. **첫 예약** — [예약 관리 > 새 예약] 또는 [예약 달력]에서 빈 칸을 끌어 선택 → **[선택 기간으로 새 예약]**.

## 2. 하루 업무 흐름

| 할 일 | 화면 |
|---|---|
| 오늘 나갈 장비·돌아올 장비·연체 확인 | **대시보드** |
| 장비별 일정 보기, 빈 기간에 예약 | **예약 달력** |
| 예약 만들기·확정·취소·연장 | **예약 관리** |
| 장비 내주기(출고), 돌려받기(반납) | **출고/반납** |
| 받을 돈·돌려줄 보증금 정리 | **정산 내역** |
| 고장 장비 예약 막기 | **정비 관리** |
| 엑셀 보고서 | **보고서** |

## 3. 예약

- **임시저장** 예약은 장비를 잡아 두지 않습니다. **확정**해야 그 기간에 장비가 묶이고, 같은 장비의 겹치는 확정 예약은 저장되지 않습니다.
- 예약 기간은 시작 시각부터 끝 시각 **직전까지**입니다. 반납 후 준비 시간(카테고리별 설정)이 있으면 그 시간도 다음 예약에서 피합니다.
- 장비 선택 표에는 고를 수 없는 장비와 그 이유(다른 예약, 정비 중 등)가 함께 보입니다.
- **장비 세트**: [장비 관리 > 세트]에서 카메라+렌즈+배터리처럼 묶어 두면 예약할 때 [세트 추가]로 한 번에 담고, 같은 카테고리의 다른 장비로 바꾸거나 뺄 수 있습니다.
- **요금 방식**: 1일, 1박 2일, 주말, 주 단위, 월 단위(설정 > 요금 계산 방식, 카테고리별 설정).
- **예약금·선입금**: 확정 예약의 [예약 상세]에서 받은 돈을 기록합니다.
- **취소**: 취소 수수료를 받으면 수수료가 청구로 남고, 이미 받은 돈은 환급으로 정리합니다.
- **연장**: 대여 중인 예약의 [연장]. 연장 기간에 다른 예약이 있으면 연장되지 않습니다.

## 4. 출고와 반납

- **출고 처리**: 예약된 장비를 한 번에 모두 내줍니다(일부만 먼저 내주는 기능은 없습니다). 세트는 구성품 체크리스트로 확인합니다. 출고하면 대여확인서를 바로 열 수 있습니다.
- **반납 처리**: 장비별로 돌려받을 수 있습니다(일부 반납 가능). 늦게 돌아오면 연체료가 자동 계산됩니다(유예 시간, "연체 1일당 일 대여료의 ○배" 설정).
- 파손·분실·세척·구성품 누락 등은 **추가 비용**으로 사유와 함께 청구합니다.
- 모든 장비가 돌아오면 예약은 "반납 완료"가 됩니다. **반납 완료와 정산 완료는 다릅니다.** 받을 돈이나 돌려줄 보증금이 남아 있으면 계속 **미정산**으로 표시됩니다.

## 5. 정산과 보증금

- 대여료와 보증금은 따로 관리합니다. 보증금은 돌려주거나(반환), 받을 돈에서 뺄 수 있습니다(보증금에서 차감).
- 받은 금액보다 많이 돌려주거나, 보증금보다 많이 차감하는 저장은 막힙니다.
- [정산 내역 > 정산 열기]에서 남은 금액을 확인하고 마무리합니다. 잘못 기록한 거래는 지우지 않고 **취소 기록**으로 바로잡습니다.

## 6. 문서와 보고서

- [예약 상세 > 문서 출력]: 견적서, 대여확인서, 반납확인서를 **PDF 저장** 또는 **인쇄**.
- 약관 문구는 [설정 > 출력물 문구]에서 업체에 맞게 고쳐 쓰세요. **기본 약관은 예시 문구이며 법률 검토를 거친 문구가 아닙니다.**
- [보고서]: 장비 목록, 예약 목록, 오늘 출고·반납, 연체 목록, 정산 목록을 엑셀(.xlsx)로 저장합니다.

## 7. 데이터 백업 (꼭 읽어 주세요)

- 모든 데이터는 **이 PC에만** 저장됩니다(`%LOCALAPPDATA%\RentalDesk`). 판매자도 볼 수 없고 되살려 드릴 수 없습니다.
- **자동 백업**: 프로그램을 종료할 때 하루 1번, 최근 14개를 보관합니다([설정 > 자동 백업 폴더 열기]).
- 자동 백업은 같은 PC 안에 저장되므로, PC 고장에 대비해 **[설정 > 백업 파일 만들기…]로 USB 등 다른 곳에도 주기적으로 백업**하세요.
- **새 PC로 옮기기**: 기존 PC에서 백업 파일 만들기 → 새 PC에 설치 → [설정 > 백업에서 복원…]. 새 PC는 기기 코드가 달라 라이선스 재발급이 필요합니다.
- 복원하기 전 현재 데이터는 자동으로 보호 백업됩니다.

## 8. 라이선스

- 라이선스 1개 = PC 1대. [설정 > 라이선스]에서 상태, 만료일, 사용 가능 버전, 이 PC의 기기 코드를 볼 수 있습니다.
- **1개월 라이선스**는 만료 7일 전부터 화면 왼쪽 아래에 남은 기간이 표시됩니다. 기간이 끝나면 실제 데이터 화면이 열리지 않지만 **데이터는 지워지지 않고**, [실제 데이터 백업…]으로 꺼낼 수 있으며, 새 라이선스를 등록하면 그대로 이어서 씁니다.
- **업데이트**: 오류 수정 버전(예: 1.0.1)은 무료로 바로 쓸 수 있습니다. 새 기능이 들어간 버전(예: 1.1)은 업데이트를 구매하고 새 라이선스 파일을 받아야 실행됩니다. 업데이트를 사지 않으면 지금 버전을 계속 쓰면 됩니다.

## 9. 지원하지 않는 기능

여러 PC·직원이 같은 데이터를 함께 보기, 문자·알림톡 발송, 카드 결제 연동, 세금계산서 발행, 모바일 앱, 장비 사진·바코드, 수량으로 관리하는 소모품 재고, 일부 장비만 먼저 출고.

## 10. 문제가 생겼을 때

- 프로그램이 이상하게 동작하면 [도움말 > 프로그램 정보·문의 > 오류 기록 폴더 열기]의 기록 파일과 함께 크몽 메시지로 알려 주세요. **고객 정보가 든 데이터 파일(.db)이나 백업 파일은 보내지 마세요.**
- 화면이 너무 크거나 작으면 [설정 > 화면 크기]에서 바꿉니다.
