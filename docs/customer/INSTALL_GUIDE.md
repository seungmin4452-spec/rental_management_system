# RentalDesk 설치 안내서 (Windows 11)

> 고객에게 PDF로 보내는 원고입니다. `[그림 n]` 자리에 `docs/customer/images/`의 그림을 넣습니다.
> **그림 1~5(다운로드·SmartScreen·설치 화면)는 K2 깨끗한 PC 검증 때 캡처**해야 합니다. 앱 화면 그림(6·8·9)은 `scripts/make_guide_shots.py`로 만듭니다.
> 개발자용 상세 안내는 `docs/install_windows.md`.

---

## 준비물

- **Windows 11 (64비트)** PC — 시작 버튼 우클릭 > [시스템]에서 "Windows 11"과 "64비트"를 확인하세요. Windows 10에서는 설치가 진행되지 않습니다.
- 판매자가 크몽 메시지로 보낸 설치 파일: `RentalDesk_1.0.0_win-x64_setup.exe`
- 관리자 권한은 필요 없습니다.

## 1단계. 설치 파일 받기

크몽 메시지의 파일을 내려받습니다. 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 막으면:

- **Edge**: 다운로드 목록의 파일 옆 **[…]** → **[유지]** → **[자세히 표시]** → **[그래도 유지]**
- **Chrome**: 다운로드 목록에서 **[계속]** 또는 **[유지]**

`[그림 1] Edge 다운로드 경고와 [유지] 버튼`

## 2단계. "Windows의 PC 보호" 화면이 나오면

RentalDesk는 개인 개발 프로그램이라 마이크로소프트 코드 서명이 없습니다. 그래서 처음 실행할 때 파란 경고 화면이 나옵니다. 프로그램에 문제가 있다는 뜻이 아닙니다.

1. 파란 화면에서 **추가 정보**를 누릅니다. `[그림 2]`
2. 아래에 나타나는 **[실행]**을 누릅니다. `[그림 3]`

> **크몽 메시지가 아닌 곳에서 받은 파일이면 실행하지 마세요.** 백신이 "트로이 목마"처럼 구체적인 위협 이름을 표시하면 설치를 멈추고 크몽 메시지로 알려 주세요.

## 3단계. 설치하기

1. 설치 화면에서 **[다음]**을 눌러 진행합니다. 바탕 화면 바로가기를 원하면 체크합니다. `[그림 4]`
2. 마지막 화면에서 **[RentalDesk 실행]**이 체크된 채 **[마침]**을 누릅니다. `[그림 5]`

## 4단계. 기기 코드 보내기

1. 처음 실행하면 **라이선스 확인** 창이 열립니다. `[그림 6]`
2. "이 PC의 기기 코드" 옆 **[복사]**를 누르고, 크몽 메시지에 붙여 넣어 보내 주세요. 라이선스에 표시할 **상호명**도 함께 알려 주세요.
3. 라이선스 파일을 받기 전까지 **[예제 데이터로 체험]**으로 모든 기능을 써 볼 수 있습니다. 예제 데이터는 실제 데이터와 따로 저장되고, 라이선스를 등록해도 실제 데이터로 섞이지 않습니다.

## 5단계. 라이선스 파일 등록

1. 판매자가 보낸 `RentalDesk_….json` 파일을 내려받습니다.
2. 프로그램을 실행해 라이선스 창의 **[라이선스 파일 불러오기…]**를 누르고 받은 파일을 고릅니다. (예제 데이터 모드에서는 [설정 > 라이선스]에서 같은 버튼을 씁니다.) `[그림 6]`
3. "라이선스를 등록했습니다"가 나오면 실제 데이터 화면이 열립니다. 왼쪽 아래에 **"정품 · 이 PC 1대"**가 보이면 완료입니다. `[그림 8]`

## 6단계. 시작 도우미

실제 데이터가 비어 있으면 "취급하는 장비를 모두 고르세요" 창이 나옵니다. 해당하는 장비 종류를 고르면 카테고리와 추천 설정이 준비됩니다(나중에 [도움말 > 시작 도우미]로 다시 열 수 있음). `[그림 9]`

이후 사용법은 `사용 설명서`를 보세요.

## 자주 묻는 질문

**업데이트 설치는?** 새 설치 파일을 실행하면 기존 프로그램 위에 설치되고 데이터는 그대로 남습니다. 실행 중인 RentalDesk는 먼저 종료하세요. 오류 수정 버전은 지금 라이선스로 바로 쓸 수 있고, 새 기능 버전(유료 업데이트)은 함께 보내 드리는 새 라이선스 파일을 등록하세요.

**프로그램을 지우면 데이터도 지워지나요?** 아니요. 데이터는 `%LOCALAPPDATA%\RentalDesk`에 남습니다.

**PC를 바꾸면?** 기존 PC의 [설정 > 백업 파일 만들기…] → 새 PC에 설치 → [설정 > 백업에서 복원…]. 새 PC의 기기 코드로 라이선스 재발급(유료)이 필요합니다.
