# RentalDesk 릴리스 노트

버전 규칙: `주.부.수`. 오류 수정만 들어가면 끝자리(1.0.**1**), 새 기능이 들어가면 가운데 자리(1.**1**.0)를 올립니다.
오류 수정 버전은 구매하신 라이선스로 바로 쓸 수 있고, 새 기능 버전은 업데이트 구매 후 새 라이선스 파일이 필요합니다.

## 1.0.0 — 첫 판매 버전 (2026-10)

지원 환경: Windows 11 (64비트). Mac·Windows 10은 지원하지 않습니다.

### 들어 있는 기능

- **예약**: 장비 한 대마다 고유 번호, 겹치는 확정 예약 저장 차단, 예약 달력, 한 예약에 여러 장비, 장비 세트(키트), 예약 연장, 예약금·선입금, 취소와 취소 수수료
- **출고·반납**: 대시보드(오늘 출고·반납·연체), 장비별 일부 반납, 세트 구성품 체크리스트, 추가 비용(파손·분실·세척·구성품 누락·기타), 정비 기간 예약 차단
- **요금·정산**: 1일·1박 2일·주말·주·월 요금, 카테고리별 설정, 연체료 자동 계산(유예 시간·배수·시간 단위), 대여료·보증금 분리, 보증금 차감·반환, 미정산 표시, 정산 마무리
- **문서·보고서**: 견적서·대여확인서·반납확인서 PDF·인쇄(약관 문구 수정 가능), 엑셀 보고서 5종, 장비·고객 엑셀 가져오기
- **데이터**: 종료 시 하루 1회 자동 백업(최근 14개), 백업 파일 만들기·복원(복원 전 보호 백업), 예제 데이터 체험 모드, 시작 도우미
- **라이선스**: PC 1대 오프라인 라이선스, 1개월 라이선스 만료 7일 전 안내, 업데이트 허용 버전 확인

### 알려진 제한

- 여러 PC 데이터 연동, 문자·알림톡, 카드 결제, 세금계산서, 모바일 앱, 장비 사진·바코드, 일부 출고는 지원하지 않습니다.
- 설치 파일에 코드 서명이 없어 설치할 때 Windows "PC 보호" 경고가 나올 수 있습니다(설치 안내서 참고).
- 대여확인서 기본 약관은 예시 문구입니다. 업체에 맞게 고쳐 쓰세요.
